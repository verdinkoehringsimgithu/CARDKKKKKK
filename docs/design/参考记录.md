# 参考记录

本轮查了开发者更新和官方截图，没有亲自运行参考游戏。下面分别记已核对的内容与项目采用的规则。

## Card Survival: Tropical Island

[Update 6，开发者公告](https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/3938951840892613694)：营火、炉灶燃烧一段时间后会留下木炭和灰；灰须熄火后取。灰水能做碱液，碱液与脂肪能做肥皂，肥皂减少洗澡用水。工具部分还写了泥模、窑炉、铜刃到工具的加工关系。

这条链的价值在于取料有条件，制成品改变以后的用水。项目先试“等待加工，同时做别的；副产物改善容器”，不把洗澡、疾病和完整冶金一起搬进来。

[2022 蓝图讨论中的开发者回复](https://steamcommunity.com/app/1694420/discussions/0/3427823723504196432/)说明为什么让需求可查、又不一次给玩家太多蓝图。这个旧蓝图商店已被[正式版研究系统](https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/6258337460548878530)替换。旧帖仅用于理解信息呈现问题，不当成当前系统说明。

实际查看的官方图：[开局](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/1694420/ss_105e8034aa4b7f428ea8d00bf97f7fa5cd3fbf45.1920x1080.jpg)、[营地与库存](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/1694420/ss_0bcb840558d9226f63a788fd8b50469a696d9eaa.1920x1080.jpg)。地点、设施、库存分行；卡面写对象、数量和状态。游戏状态很多，但屏幕上没有开发方法和配置路径。

## Oxygen Not Included

[Automation Upgrade 公告](https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/2486412956102322922)明确提到金属精炼的高效率与排出热液体。液体还是可处理的对象，热会跟它走。把这关系替换成全局热值和一个减热按钮，会省掉一部分工艺安排，本项目撤回了那种设计。

[官方 QoL 更新](https://steamstore-a.akamaihd.net/news/externalpost/steam_community_announcements/1816849002011812)将种子用途放回植物条目，补充材料转化和食谱关联。项目采用“从选中物件查相关用途”的做法。

Steam 公告外链部分不受网页抓取支持，本轮通过 Steam 官方新闻 API 按公告 ID 核对原文与链接；没有把论坛玩家配方或旧版本数值写成本案规则。

## 对旧案的处理

《余烬工坊》旧案停用，原文和数据留在 Git 历史。十四天、两名工人、半日排班、三次相同修塔和全局热条均退出当前方案。旧通关账本只能证明那份规则的数字可达，不能作为玩法成立的依据。

当前只采用[制作原型](制作原型.md)。它仍要试玩，尤其要看修补容器带来的收益是否值得前面的加工时间。首轮没有证据支持继续扩种植、天气或金属加工。
