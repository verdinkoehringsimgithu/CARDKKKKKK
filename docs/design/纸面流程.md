# 纸面流程与观察开局

2026-11-04。以下根据[首版策划](制作原型.md)手工核算，没有执行程序、Unity 或测试，也没有穷举所有顺序。它只检查已列路线能按规则走完，不证明最优、平衡或好玩。

## 完整首段：从原料到铜斧

起始木料 8、黏土 4、纤维 1、铜矿 4，其他 0；一座空窑、工作台，没有炉衬。

### 路线一：两次快烧，先装炉衬

| 游戏分钟 | 人物与工位 |
|---|---|
| 0～15 | 第一次快烧准备；窑立即占用 |
| 15～60 | 窑后台快烧；人物捡木一次，得到木料 4 |
| 60～90 | 用灰 1、黏土 2 安装炉衬；窑占用 |
| 90～105 | 第二次快烧准备 |
| 105～150 | 窑后台快烧；人物在 105～120 用黏土 2 捏坯，之后等待 |
| 150～165 | 投入陶坯 1、木炭 1，准备烧坩埚 |
| 165～225 | 窑烧坩埚，等待完成 |
| 225～240 | 普通熔铜准备，耗矿 2、炭 1 |
| 240～300 | 熔铜后台，得到铜锭 1 |
| 300～315 | 第二批普通熔铜准备，耗矿 2、炭 1 |
| 315～375 | 熔铜后台，得到第二块铜锭 |
| 375～405 | 用铜锭 2、木料 1、纤维 1 装配铜斧 |
| 405～435 | 持铜斧采集，木料 4；目标完成 |

总用时 435 分钟，制作投入木料 9，含制炭 8 和斧柄 1。终点木料 7、木炭 1、灰 1、坩埚 1、铜斧 1，窑有炉衬；其他库存为 0。

这一安排含一次额外捡木。炉衬与存炭是继续生产时的收益，不应在结尾隐藏。

### 路线二：一次快烧，一次封窑，不装炉衬

| 游戏分钟 | 人物与工位 |
|---|---|
| 0～15 | 快烧准备 |
| 15～60 | 窑后台快烧；人物在 15～30 用黏土 2 捏坯，之后等待 |
| 60～90 | 封窑准备，投入木料 3 |
| 90～180 | 窑后台封窑制炭，得到炭 2、焦油 1 |
| 180～195 | 投入陶坯 1、木炭 1，准备烧坩埚 |
| 195～255 | 烧坩埚后台 |
| 255～270 | 助燃熔铜准备，耗矿 2、炭 1、焦油 1 |
| 270～300 | 助燃后台，得到铜锭 1 |
| 300～315 | 普通熔铜准备，耗矿 2、炭 2 |
| 315～375 | 熔铜后台，得到第二块铜锭 |
| 375～405 | 用铜锭 2、木料 1、纤维 1 装配铜斧 |
| 405～435 | 持铜斧采集，木料 4；目标完成 |

总用时同为 435 分钟，制作投入木料 8。不需额外捡木。终点木料 4、黏土 2、灰 1、坩埚 1、铜斧 1，没有炉衬；炭与焦油用完。

终点若只看这把斧子，路线二的木耗和操作更少。路线一的收益在继续经营时更明显。两条可达不等于它们一样划算，不能用这份账本代替玩家判断。

## 五工艺灰盒：只观察加工选择

灰盒仅包括快烧、封窑、装炉衬、普通熔铜、助燃熔铜。开局送坩埚，不制作铜斧；三种地点的四种采集操作都开放。五工艺均已知，避免解锁干扰比较。

目标都是铜锭 3。配方和操作耗时与完整首段相同，不设硬截止。两个开局只换库存：

| 库存或状态 | A：已有存炭 | B：资源未备 |
|---|---:|---:|
| 木料 | 8 | 3 |
| 黏土 | 2 | 0 |
| 铜矿 | 6 | 6 |
| 木炭 | 1 | 0 |
| 灰、焦油、铜锭 | 0 | 0 |
| 坩埚 | 1 | 1 |
| 炉衬 | 无 | 无 |

A 的一条可行路线：一次快烧 60 分钟，安装炉衬 30 分钟，三次普通熔铜各 75 分钟。总 315 分钟，投入木料 4。原炭 1 加新炭 2 正好用完。

B 的可行路线包括：

| 路线 | 安排要点 | 总分钟 | 制作投入木料 | 特点 |
|---|---|---:|---:|---|
| 封窑两次 | 第一批后台捡木；最后助燃两次、普通一次 | 405 | 6 | 省木，结束无炉衬 |
| 封窑＋快烧＋炉衬 | 第一批后台捡木并取黏土；最后助燃一次、普通两次 | 405 | 7 | 留炉衬和炭 1 |
| 快烧两次＋炉衬 | 开始先捡木，第一批后台再捡木，第二批后台取土 | 420 | 8 | 路线仍开放，但当前资源准备较麻烦 |

B 的快烧路线不是全局最优结论，只是一条核对过的安排。不要为使表格“只有一个正确答案”而删掉混合工艺。

### 后续实际操作时记什么

先让玩家熟悉如何开工，再交换 A、B 的先后顺序。不要在其选择前解释哪条是预期路线。

记录第一次和第二次制炭、是否改炉、焦油用在哪一批、操作前有没有查看工位剩余时间。问“刚才为什么选这条”，不要只问“好不好玩”。

若玩家能根据初始库存改变顺序并说清代价，可以继续做完整首段；若总是无差别点一条，先核对信息是否看得懂，再改配方。若只是记住了 A/B 标准答案，这两开局只能说明教学有效，不能说明长线选择成立。

无硬截止时，时间主要作为比较指标；没有在意用时的玩家可能偏向省料。此时应记录这一反馈，不把缺少实际压力解释为玩家没理解。
