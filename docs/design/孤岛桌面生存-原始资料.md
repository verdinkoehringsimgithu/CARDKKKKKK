# 孤岛桌面卡牌生存游戏：基础设计与配方系统规划

## 一、项目概述

本项目计划制作一款以孤岛生存为背景、以卡牌为主要交互形式的桌面管理游戏。

游戏参考《密教模拟器》的桌面操作与时间机制、《缺氧》的资源循环和动植物生产体系，以及《卡牌生存》的生存、采集、制作和长期发展内容。

玩家在一座资源有限的孤岛上生活，通过采集、制作、烹饪、农业、畜牧和资源回收维持生存，并逐步建立更加复杂的生产体系。

游戏的主要特色确定为三个方面：

1. **人造生态：** 通过种植、养殖、育种和生态组合，使动植物成为持续生产和转化资源的手段。
2. **废料再利用：** 生产和生存活动不断产生副产物及废料，玩家逐渐发现它们的新用途，建立新的生产关系。
3. **资源的熵增：** 工具、设施和资源在使用及时间流逝中持续损耗，维修、拆解和回收构成长期的资源消耗与管理需求。

三者共同形成游戏的主要进程：玩家不断消耗资源、产生副产物、遇到新的生产瓶颈，再通过材料加工、生物研究和生态建设改善原有的资源循环。

这里所强调的熵增，是一种游戏机制上的持续损耗、状态变化和后果积累。玩家的行动会留下需要管理的结果，而处理这些结果也会消耗时间和资源。

## 二、桌面与五类卡牌

游戏发生在一张代表孤岛的矩形桌面上，采用卡牌自由拖动、堆叠、组合和放置的交互方式。

初始桌面可操作面积较小，需要后续解锁。

游戏采用五种基础卡牌分类：

| 类型 | 主要功能 |
|---|---|
| 材料卡 | 资源、食物、废料、加工产物等，可以被消耗、转化和堆叠 |
| 工具卡 | 提供切割、打磨、采集等能力，拥有材质、硬度和耐久度 |
| 设施卡 | 执行制作、烹饪、加工等配方，例如篝火 |
| 区域卡 | 类似花圃、围栏、堆肥区的可拖动小型边框，对框内卡牌施加规则 |
| 生物卡 | 植物和动物，可以生长、繁殖、消耗资源和持续产出物品 |

装备系统作为角色自身的使用位置存在，可以将装饰品以工具卡形式装备到角色身上。装备效果除了改变精神、健康等数值，也可以影响部分行动的效率和副产物产生概率。

### 区域设计

区域卡具有收纳与环境规则功能。

花圃可以容纳植物、土壤和肥料，围栏可以容纳动物和饲料，堆肥区可以容纳有机废物及分解生物。区域本身占用的桌面面积有限，可以自由移动。

区域中的卡牌可以按照时间和条件持续变化，玩家通过调整内容物形成不同的生产组合。

### 时间与环境

时间流逝会影响卡牌状态，包括腐败、生产、消耗、磨损等。

后期可以增加夜晚遮蔽效果，使黑暗区域中的部分卡牌无法直接点击，从而引入光照的实际用途。

孤岛也可以周期性接收潮汐带来的材料，为游戏提供有限、具有随机性的外部资源输入，作为早期的重要物资来源。

## 三、现有玩法思维导图

目前的系统主要围绕生存状态、农业、畜牧、制作与资源管理展开。

### 1. 生存状态

**饥饿：** 采集、烹饪、食物储存、调味。

**健康：** 草药、绷带、夹板、防虫以及其他医疗用品。

**生命：** 生存风险、伤害、治疗及相关装备。

**精神：** 装饰、装备、环境和部分生活活动对精神状态的影响。

这些需求提供持续的生存压力，使玩家获得的材料和制作的物品具有实际用途。

### 2. 农业

包括耕田、种子收集、种植、收获、肥料、工具、授粉、育种和杂交。

农业既是食物来源，也是纤维、药用植物及其他生产材料的来源。

农业会消耗工具耐久和土壤养分，也会产生植物残渣等副产物。肥料和废物处理因此能够与农业形成直接联系。

### 3. 畜牧

包括捕获、喂养诱导、围栏、饲料、饲料容器、繁殖和遗传变异。

动物可能持续提供食物、特殊材料、粪便或其他副产物。

某些生物能够消耗普通生产方式难以利用的物质，将其转化为稀缺材料。畜牧因此承担改善资源结构的作用。

### 4. 工具、制作与资源管理

包括工具制作、材质差异、耐久度、维修、拆解、存储，以及废弃物处理。

工具的硬度、耐久和加工能力需要分别考虑。不同材质可以长期具有各自的用途，不必建立单纯的材料等级替代关系。

存储和整理也应具有实际意义，但需要避免让大量重复拖卡操作成为主要负担。

### 5. 育种与生态组合

农业和畜牧最终可以汇入育种、遗传变异及生态组合系统。

玩家通过发现不同动植物之间的关系，调整生长、繁殖、饲料和废物处理条件，建立人工维持的生态系统-区域卡，类似系统，有固定的摄入和产出。

生态组合的价值包括提高产量、改变资源消耗方式、减少维护成本，以及创造原本无法持续获得的材料。

## 四、以自然节点约束配方树

配方设计需要先确定世界中存在的具体对象，再根据对象的自然属性和加工方式推导合理的材料与用途。

例如确定「帽贝岩」这一节点以后，它的产物就应当围绕帽贝、贝壳、附着的藻类和岩石展开。这样能够约束后续配方的设计范围，减少任意添加材料和不合理产物的问题。

节点可以描述资源来源、生物、设施等不同对象。它们在游戏内仍然归属于前述五类卡牌，无须为节点建立第六种卡牌分类。

目前已经形成以下三个基础节点。

| 规则 | 帽贝岩 | 篝火 | 芦荟 |
|---|---|---|---|
| 持续生产 | 贝壳 | 无 | 芦荟肉 |
| 寿命 | 无限 | 有限 | 自然生成的个体无限 |
| 耗尽产物 | 无 | 灰烬 | 腐烂物 |
| 修补材料 | — | 可燃物 | 腐烂物、废料 |
| 副产物 | 黑藻 | 炭 | 无 |
| 破坏产物 | 石头 | 炭、木头 | 芦荟肉 |

这些节点体现了一套可以复用的设计语言。

持续生产决定长期资源来源；寿命与耗尽产物决定自然变化；修补决定维持成本；副产物决定附加产出；破坏产物则允许玩家主动结束一个节点，并获取相应资源。

同一个节点可以同时提供长期收益和一次性收益。例如帽贝岩可以持续提供贝壳，但破坏后才能获得石头，玩家需要在持续生产和立即取得材料之间作出选择。

### 帽贝岩的配方分支

帽贝可以进一步区分为贝壳肉、大贝壳和小贝壳。

- 贝壳肉可以直接食用，也可以参与煮汤。
- 小贝壳主要用于装饰品，装备后可以提供精神收益或改变特定行动的概率。
- 大贝壳可以加工成贝壳刀。

贝壳刀材料容易获得，耐久较低，硬度有限，适合日常切割、刮取等操作。

燧石较为稀缺，硬度更高，可以加工成更耐用的刀具，也可以在未经精细加工的状态下用来打磨贝壳。

因此，玩家可以选择保留稀缺燧石，通过反复制作贝壳刀满足日常需求。这会增加制作时间和操作成本，但能够减少珍贵材料的消耗。

这样的工具关系具有长期的资源取舍，贝壳刀与燧石刀都可以保留实际用途。

### 芦荟的配方分支

芦荟可以持续产出芦荟肉。

芦荟肉能够直接食用，也可以作为素食材料参与烹饪。

玩家使用具有切割或刮取能力的刀具，可以从芦荟肉中加工出芦荟凝胶。

芦荟凝胶进一步用于烧伤药膏和叮咬药膏。

掌握相应技术以后，玩家可以通过分株繁殖芦荟，将原先依赖自然资源的采集方式转变为人工种植。

由此，一个自然节点能够同时连接食物、工具、医疗和农业系统。

## 五、三大特色如何贯穿游戏进程

### 人造生态

人工生态系统应当随着玩家掌握的生物种类、繁殖技术和材料加工能力逐渐发展。

最初，玩家主要依赖自然生成的动植物。后来通过花圃、围栏等区域进行种植和养殖，再通过饲料、肥料、遗传变异和生态组合改进生产。

其重要成果是让有限资源获得新的持续生产途径。

例如某种生物能够消耗大量积累的有机废物，并持续产出可用于制造工具的特殊材料。这种发现会直接改变已有的工具生产体系。

### 废料再利用

废料需要从游戏早期就存在。

烹饪产生灰烬，食物腐烂产生有机废物，工具制作和拆解产生碎屑，生物活动产生排泄物或残渣。

初期玩家可能只能存储、丢弃或使用低效率的方法处理其中部分废料。

随着新的设施、生物和配方出现，废料逐渐进入其他生产链。

这种机制必须保留一定的资源处理压力。可以允许废物被销毁或交易，但不宜提供一个能够随时、无代价处理所有物品的统一出口。

需要避免通过单纯增加废料种类制造操作负担。具有代表性的废料可以从早期贯穿到后期，并随着玩家掌握的技术逐渐获得更多用途。

### 耐久度的熵增

工具和部分设施会随着使用逐渐损坏。

维修需要材料和时间，拆解只能回收部分资源，反复修理可能降低工具的最大耐久度。

材料硬度决定工具的适用范围，耐久度决定可持续使用的次数，资源稀缺程度则影响玩家如何选择工具。

不同材质工具之间应当形成使用成本、加工能力和材料供应方面的差异。

农业、畜牧和废料回收可以提供新的工具材料，逐步改变玩家维持工具供应的方式。

## 六、从节点关系推导游戏流程

游戏进程应主要从资源供需关系中产生。

当某种资源持续消耗而补充速度不足时，玩家就需要寻找新的生产途径。

当某种副产物不断积累时，玩家需要找到处理或利用它的方法。

当工具频繁损坏、有限材料逐渐减少时，玩家需要考虑修理、回收和替代材料。

这些问题推动农业、畜牧、育种、特殊材料加工等系统逐渐进入游戏。

后期出现的新配方，还应能够重新利用玩家在前期已经认识的材料。

例如，早期作为废料的某种残渣，可能在获得特定生物以后成为饲料；该生物的产物又能替代一种难以补充的工具材料。

这类关系可以让玩家的资源知识持续积累，也让不同生产方式保留实际价值。

游戏可以存在长期目标，但不需要让所有玩法都依赖严格的线性解锁。玩家能够自行安排短期活动，例如处理一批废料、制作工具、完成一次育种或改善一个生产区域。

## 七、后续规划

当前项目已经具有桌面卡牌与制作玩法的开发基础，接下来需要优先建立能够持续扩展的内容数据体系。

第一步是固定五类卡牌的数据结构，以及常用的时间变化、耐久、材料加工和产出规则。

第二步是建立节点与配方编辑器，支持创建节点、记录产出、关联已有对象、延伸配方，以及查看局部关系。

第三步是以帽贝岩、篝火、芦荟等现有节点为起点，逐步建立早期食物、工具、医疗和基础生产关系。

第四步是围绕已经形成的配方网络，检查哪些资源会耗尽、哪些废料会积累、哪些材料缺少有效用途，并进一步设计适合的生态和回收节点。

第五步再通过完整关系总览整理实际的游戏发展顺序，逐步扩大内容范围。

这一阶段应优先确保节点属性、配方关系和数据引用方式足够稳定，避免在基础结构尚未确立时大量增加材料和制作内容。

最终，配方系统需要同时承担两种作用：在设计阶段，用具体自然对象约束内容的扩展；在游戏运行中，通过有限资源、持续生产、废料转化和耐久损耗，使玩家逐渐建立更加复杂的生存与生产体系。
