# 余烬工坊策划数据草案

主策划案：`docs/superpowers/specs/2026-11-03-ember-workshop-design.md`。

- `卡牌表.csv`：24 个定义，14 种库存物品、6 种设施、3 个地点、1 种工人定义（实例两个）。
- `配方表.csv`：18 条明确配方。投入/产出格式为 `技术ID:整数数量`，多项用 `|` 分隔，空值表示没有物品。
- `剧本.json`：原型起始值、上限、消费、目标和确定性结算设置。
- `通关账本.csv`：与主策划案一致的 14 日构造性通关路线；不是最优解或平衡结论。
- `开发任务.csv`：按依赖和验收条件拆分的两人开发任务。
- `static-balance-check.json`：逐时段静态核算记录，覆盖工位、工人、材料、热和夜间供给；不包含游戏运行结果。

数据用于策划审核和后续制作资产。**当前项目尚未实现这些生产系统，也没有直接读取这些表格的运行逻辑或导入器。** 本次没有编译或运行游戏。

数字统一为原型假设。修改消费、配方和工时后，需要重新核算通关账本和观察试玩；文件格式可解析不表示玩法已经验证。
