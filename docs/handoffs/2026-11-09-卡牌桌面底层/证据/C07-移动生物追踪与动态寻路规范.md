# C07 - 移动生物追踪、寻路目标查询与暂停钩子规范

> **规范等级**：
> - **E2 / D（自主移动实体行为树与目标查询规范）**：以孤岛出航规则中的“雏鸟觅食（Bird Foraging）”为核心范例，建立通用的桌面移动生物追踪、目标防抢与动态重查机制。
> - **核心准则**：严禁在玩家拖动卡牌或卡牌处于任务锁定时被生物抢食；游戏处于暂停掩码时生物行动绝对冻结；目标被外部消耗时必须安全重查，杜绝空引用异常。

---

## 一、生物寻路与目标安全查询管线（Creature Target Query Pipeline）

```mermaid
flowchart TD
    TickStep[时钟 Phase 5 触发生物行动] --> CheckPause{PauseMask != 0 ?}
    CheckPause -- 是 (暂停态) --> Freeze[行动冻结: 保持原地不动]

    CheckPause -- 否 (时间流逝) --> ScanTargets[扫描感知范围 BirdRange 内的候选食物卡牌]

    ScanTargets --> Filter1{食物是否正被玩家拖拽 (InDragSession)?}
    Filter1 -- 是 --> Discard[忽略: 不抢玩家手中的牌]

    Filter1 -- 否 --> Filter2{食物是否在卡槽中或已被加锁 (TaskLock)?}
    Filter2 -- 是 --> Discard[忽略: 不抢工坊槽位内的物资]

    Filter2 -- 否 --> Filter3{食物是否已被销毁或归属于无效容器?}
    Filter3 -- 是 --> Discard[忽略: 过滤失效实体]

    Filter3 -- 否 (完全合法) --> PickNearest[选取最近的有效目标 Target]
    PickNearest --> MoveStep[向目标方向移动一个步长 BirdStep]
    MoveStep --> CheckReach{距离目标 <= BirdReach ?}
    CheckReach -- 已到达 --> ConsumeFood[进食结算: 饱食度恢复 / 触发雏鸟蜕变事件]
    CheckReach -- 未到达 --> WaitNextMinute[等待下一逻辑分钟继续移动]
```

## 二、目标失效重查机制（Target Invalidation & Retargeting）

桌面环境充满动态变数（例如：雏鸟正向一块肉走去，但玩家在途中用鼠标将该肉拖入火堆烤制）：

1. **瞬时解绑（On-the-fly Invalidation）**：
   - 生物在每步位移或尝试进食的瞬间，必须执行严格的有效性二次断言：
     $$\text{IsTargetValid}(Target) == \text{true} \land Target.IsLocked == \text{false} \land Target.IsDragging == \text{false}$$
2. **安全放弃与重寻目标**：
   - 一旦检测到目标已被外部事件借走或销毁，生物立即放弃旧目标指针，置 `Target = null`；
   - 重新执行广度优先扫描，若周围已无其它食物，则进入待机打盹状态，绝不产生 `NullReferenceException` 或凭空吞空气。
