# B01 - 拖拽会话、抓取偏移与堆叠拆分规范

> **规范等级**：
> - **E2 / D（桌面空间交互与拖拽会话实现规范）**：定义玩家从按下光标、区分点按与拖动、记录抓取偏移、分离单牌/子堆/整堆，到取消恢复的原生交互逻辑。
> - **核心准则**：点按不误触发拖动；抓牌时卡牌绝对不向光标中心瞬移；非法目标或取消后卡牌必须精确原位恢复，无残留位移。

---

## 一、输入判定与拖动阈值（Drag Threshold）

为解决鼠标轻点查看详情却意外引起卡牌位移的抖动问题，交互系统引入**像素拖动死区阈值**：

```mermaid
flowchart TD
    PointerDown[光标按下: PointerDown] --> RecordStart[记录起始屏幕坐标 StartPointerPos]
    RecordStart --> SetHoverState[触发选中/高亮 SelectionChanged]

    SetHoverState --> PointerMove[光标移动: PointerMove]
    PointerMove --> CheckThreshold{|CurrentPos - StartPos| >= DragThreshold (6px)?}

    CheckThreshold -- 否 (处于死区内) --> KeepStatic[保持静态: 不创建拖动会话, 仅为点击预备]

    CheckThreshold -- 是 (超出阈值) --> CheckModifier{检查修饰键 (Ctrl / Shift)}
    CheckModifier -- 无修饰键 (默认) --> DragSubStack[拖动子堆: 从被点中卡牌至堆顶全部卡牌]
    CheckModifier -- 按住 Shift/Ctrl --> DragSingle[单牌分离: 仅拖动当前点中的单张卡牌]

    DragSubStack --> StartSession[启动 DragSession: 提至 DragLayer, 记录抓取偏移]
    DragSingle --> StartSession
```

- **阈值设定**：默认 `DragThreshold = 6.0f` 像素；
- 在光标移动未超过阈值前松开，判定为单纯**点击（Click）**，仅触发选择（`Select`）或翻面，不启动核心拖拽流程。

## 二、抓取偏移（Grab Offset）与零跳变法则

在许多粗糙的卡牌实现中，一旦抓起卡牌，卡牌中心点会瞬间跳跃贴合到鼠标尖端，产生严重的视觉跳变与漂移感。

### 1. 抓取偏移计算公式
当按下位置落在卡牌矩形内的任意点时：
$$\vec{Offset} = \vec{PointerWorldPos} - \vec{CardPivotWorldPos}$$

在后续每帧拖拽更新中：
$$\vec{CardTargetWorldPos} = \vec{CurrentPointerWorldPos} - \vec{Offset}$$

### 2. 堆叠相对位置保持
若拖拽的是包含多张卡牌的堆叠（如拖动子堆 $[C_1, C_2, C_3]$）：
- 主卡（点中的底牌 $C_1$）按 $\vec{TargetPos} = \vec{Pointer} - \vec{Offset}$ 计算；
- 后续子卡 $C_{i}$ 严格按堆叠纵向间距偏移：
  $$\vec{CardPos}(C_i) = \vec{TargetPos} + (0, i \times PileOffset)$$
- 拖动过程中堆内卡牌相对位置完全刚性锁定，绝不发生相对抖动。

## 三、单牌、子堆与整堆的分离逻辑

牌堆从底到顶为有序列表 $[C_0, C_1, C_2, \dots, C_{n-1}]$：

1. **整堆拖动（Whole Pile Drag）**：
   - 当点击底牌 $C_0$ 拖拽，或直接拖拽牌堆整体时，整堆全部 $n$ 张卡牌打包进入 `DragSession`；
   - 原桌面牌堆保留临时占位符或完全拉起。
2. **子堆提取（Sub-Stack Drag）**：
   - 当玩家点击堆中第 $k$ 张卡牌 $C_k$ 并拖动（未按修饰键）：
   - 提取列表 $[C_k, C_{k+1}, \dots, C_{n-1}]$ 进入 `DragSession`；
   - 原底座剩余卡牌 $[C_0, \dots, C_{k-1}]$ 仍旧保持在桌面上，原牌堆大小安全缩小为 $k$。
3. **单张拆离（Single Card Extraction）**：
   - 当玩家按住 `Shift` 或 `Ctrl` 键拖动中间卡牌 $C_k$ 时：
   - 仅将 $C_k$ 单张提取进 `DragSession`；
   - 剩余卡牌 $[C_0, \dots, C_{k-1}, C_{k+1}, \dots, C_{n-1}]$ 在原牌堆内自动收束缝合，层级依次向下闭合。

## 四、非法目标与取消恢复（Atomic Abort）

当发生以下情况时，拖动会话立即执行取消（`CancelDrag`）：
1. 玩家按下 `Esc` 键；
2. 卡牌被释放在桌外非法区域且无解；
3. 拖拽期间游戏失焦（`WindowBlur`）或打开全屏模态窗口；
4. 目标卡槽或牌堆在松手瞬间被后台任务改变状态。

### 恢复机制：
- 核心不提交任何新位置，原状态原封不动；
- 表现层启动平滑回弹动画（`Bounce / Lerp`），在 `0.18s` 内将卡牌从当前悬空位置插值移动回其原始记录坐标；
- 回弹完成后卡牌从 `DragLayer` 安全归还至 `CardLayer`，恢复原有渲染层级与堆内顺序。
