# C01 - 真实场所实体、局部独立窗口与卡槽模型规范

> **规范等级**：
> - **E1 / E2（实体与窗口解耦架构规范）**：基于 R03 对 5 对场所 Prefab 的逆向证据，彻底打破旧界面“全局集中式暂存区 + 任务列表”的单一狭隘模式，建立符合真实物理桌面体验的场所实体与局部窗口体系。
> - **核心准则**：桌面上每个场所实体拥有独立实例状态；点击不同场所打开其专属窗口；窗口开关不打断后台任务进度；两同类场所实例数据严格互斥隔离。

## 二、同类多场所实例的绝对独立性（Instance Isolation）

桌面上允许存在多个相同定义的场所（如建造了两个“工作台” `facility_workbench_1` 和 `facility_workbench_2`）：

1. **唯一状态隔离**：
   - 每个实体分配全局唯一的 `FacilityInstanceId`；
   - 卡槽从属于唯一的 `FacilityInstanceId`：`SlotBinding(FacilityInstanceId, SlotId, CardInstanceId)`；
   - 任务从属于唯一的 `FacilityInstanceId`：`Job.LocationId = FacilityInstanceId`。
2. **多任务并行互不串料**：
   - 实例 1 投入了“手 A”与“木棒”，启动制作火把任务（剩余 3 分钟）；
   - 实例 2 投入了“手 B”与“燧石”，启动打磨石刃任务（剩余 1 分钟）；
   - 点击实例 1 打开的是实例 1 的专属面板，点击实例 2 打开的是实例 2 的专属面板，绝不发生状态覆盖或串料。

## 三、卡槽（Slot）层次与空槽条件指引

每个场所窗口包含清晰的槽位层次：

```text
[ 场所标题: 工作台 ]
┌──────────────────────────────────────────────┐
│  [ 主输入槽: MainSlot ]                       │
│  (空槽时显示虚线卡框 + 幽灵文字: "放入工具")     │
├──────────────────────────────────────────────┤
│  [ 材料槽 1 ]   [ 材料槽 2 ]   [ 材料槽 3 ]   │
│  (标签: 木质)   (标签: 锋利)   (标签: 消耗品)  │
├──────────────────────────────────────────────┤
│  [ 进度条: TimerProgress (50%) ]             │
│  [ BtnStart: 开始工作 ]    [ BtnCancel: 取消 ] │
├──────────────────────────────────────────────┤
│  [ 产物临时格: cardGrid ]                     │
│  (任务完成后产物先于此处实例化，再飞向桌面)      │
└──────────────────────────────────────────────┘
```

1. **空槽幽灵指引（Ghost Hints）**：
   - 槽位未放置卡牌时，呈现半透明虚线轮廓与文字提示（如“需要手”、“需要利刃”）；
   - 当玩家在桌面上抓起满足条件的卡牌时，该槽位自动激活绿色就绪呼吸边框（`C03`）。
2. **容量与单牌独占**：
   - 单个输入卡槽同一时间只能容纳 1 张卡牌实例；
   - 拖拽卡牌靠近时，只有完全匹配槽位要求（定义/标签）才能吸附入槽。

## 四、窗口开关生命周期与后台静默执行

1. **关闭窗口（Close Form）**：
   - 玩家点击窗口右上角关闭按钮或按 `Esc` 时，仅将该窗口的 `CanvasGroup.alpha` 归零或 `SetActive(false)`；
   - **绝对不取消正在执行的任务**！
   - 桌面上的实体继续保留在桌面上，其身上挂载的 `timer_progress` 进度条在主桌面上清晰可见，让玩家在不打开窗口的情况下也能一览全桌所有设施的工作进度。
2. **任务完成与产物弹出链路**：
   - 当倒计时归零时：
     - 若窗口正处于打开状态：产物出现在 `cardGrid`，随后沿抛物线弹飞至桌面落点（`Fly2Target`）；
     - 若窗口处于关闭状态：产物直接从桌面实体的位置为起点，以抛物线弹飞散落在实体周围的桌面上，并伴随完成音效。
