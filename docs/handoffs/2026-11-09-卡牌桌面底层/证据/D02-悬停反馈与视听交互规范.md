# D02 - 悬停详情、音效映射与短错误反馈规范

> **规范等级**：
> - **E2 / D（视听反馈与用户交互体验规范）**：落实项目《协作约定》对“严禁 AI 式文案和长说明墙”、“操作帮助按需打开，成功用状态与动画反馈，错误保留具体原因”的铁律。
> - **核心准则**：界面不放任何常驻长指南；卡面只留精炼信息；音效精准映射 6 类操作事件；错误反馈轻量具体，避让交互按钮；材质与纹理复用受控，无内存泄漏。

---

## 一、信息层级与按需提示架构（On-Demand Feedback）

```text
┌─────────────────────────┐
│ [ 卡面常驻可见信息 ]     │  --> 仅保留：卡牌名称、分类插画、当前耐久/次数 (如: 4/5)
│ - 极简色块与清晰轮廓    │      禁止常驻大段功能说明或技术 ID
└────────────┬────────────┘
             │ 光标悬停 0.25s
             ▼
┌──────────────────────────────────────────────┐
│ [ 动态自适应 Tooltip 详情框 ]                 │
│ - 卡牌名称与品质标签                          │
│ - 能力标签: [木质] [易燃] [利刃]              │
│ - 精炼说明: 用于切削与防身，可参与粗制工具配方 │
│ - 状态倒计时: 距完全腐损剩余 14 分钟          │
└──────────────────────────────────────────────┘
```

- **位置策略**：在卡牌外侧 12px 处展开，四向屏幕边缘自适应，绝不遮挡卡槽与“开始”按钮。

## 二、六类核心操作音效映射表（Sound Events）

| 音效标识 (`TableSound`) | 触发场景 | 声音质感特征 | 预期音频资产 |
|---|---|---|---|
| `PickUp` | 抓起单牌或牌堆 | 干燥清脆的卡纸摩擦声 | `CardPaperDrag.wav` |
| `Drop` | 卡牌落入桌面稳定空位 | 沉实、轻柔的硬纸板敲击桌面声 | `CardTableDrop.wav` |
| `Snap` | 卡牌吸附进入卡槽 | 清爽的木质卡扣/吸合声 | `SlotSnapIn.wav` |
| `Rejected` | 非法目标松手 / 被拒入槽 | 低沉、短促的闷响摇晃声 | `ActionReject.wav` |
| `TaskStarted` | 点击开始启动配方工坊 | 齿轮转动 / 火光引燃沉浸环境音 | `WorkshopStart.wav` |
| `TaskCompleted` | 任务完成，产物飞出 | 清澈明亮的风铃 / 成果揭示音 | `TaskReward.wav` |

- **音效限制**：短时间内连续触发（如连续推开 5 张牌）时施加 $0.05\text{s}$ 冷却抑制，防止爆音。

## 三、短错误轻量气泡（Floating Bubble Toast）

1. **表现形式**：
   - 不弹打断玩家操作的模态大弹窗；
   - 在被拒绝的卡槽或卡牌正上方弹出半透明气泡文字框（字号 14pt，留白精致）；
   - 伴随轻微水平晃动（Shake，位移 $\pm 4\text{px}$，时长 $0.15\text{s}$）；
2. **显示时长**：
   - 停留 $1.5\text{s}$ 后平滑向上淡出消失；
3. **文案 Humanizer 铁律**：
   - 给出具体事实原因，拒绝模版废话：
     - 正确：“缺少 [利刃] 工具” / “这张手正在另一处工作中”；
     - 严禁：“操作失败，当前配置无法满足此接口的预设约束条件”。
