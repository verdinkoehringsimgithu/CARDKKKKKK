# B02 - 多分辨率适配、视口平移缩放与坐标投影规范

> **规范等级**：
> - **E2 / D（多分辨率几何适配与视口控制管线规范）**：解决卡牌桌面上不同分辨率逻辑坐标漂移、缩放导致落点错位、UI 滚轮误触发桌面缩放等空间几何痛点。
> - **核心准则**：多分辨率下落点判定必须在统一的 1600×900 逻辑桌面空间中进行；缩放和平移仅改变视口表现，绝对不篡改卡牌已提交的真实逻辑坐标；UI 滚动与桌面缩放严格互斥。

---

## 一、三层坐标映射体系（Three-Tier Coordinate Projection）

为了在不同分辨率（1280×720、1600×900、1920×1080、21:9 宽屏）下保持一致的物理判定，建立严格的三层坐标投影关系：

```mermaid
flowchart LR
    Screen[1. 屏幕像素坐标 (Screen Pixels)\nInput.mousePosition] --> LocalConv[RectTransformUtility\nScreenPointToLocalPoint]
    LocalConv --> LogicalDesk[2. 统一逻辑桌面坐标 (Logical Desk 1600x900)\nTablePoint(X, Y)\n- 核心状态与存档唯一标准]
    LogicalDesk --> Viewport[3. 视口表现坐标 (Viewport Presentation)\n- 相机平移 PanOffset\n- 滚轮缩放 ZoomRatio\n- 等比适配 FitBoard Scale]
```

### 1. 屏幕到逻辑桌面的转换法则
```csharp
public static bool ScreenToLogicalDesk(RectTransform boardRect, Vector2 screenPos, Camera eventCam, out TablePoint deskPoint)
{
    if (RectTransformUtility.ScreenPointToLocalPointInRectangle(boardRect, screenPos, eventCam, out Vector2 local))
    {
        // boardRect 的 pivot 设为左下角 (0, 0)
        deskPoint = new TablePoint(local.x, local.y);
        return true;
    }
    deskPoint = default;
    return false;
}
```
- 无论物理窗口缩放到何种尺寸，算出的 `deskPoint` 均位于 `[0, 1600] × [0, 900]` 的稳定坐标系中；
- 存档保存的永远是 `deskPoint`，在任何设备读档时位置绝对完全重合。

## 二、视口平移（Pan）与缩放（Zoom）共存机制

### 1. 缩放不改真实坐标原则
- 滚轮缩放驱动正交相机尺寸或桌面的整体缩放比例 `ZoomRatio`；
- 缩放变换以当前鼠标光标在逻辑桌面上的对应点为锚点：
  $$\vec{Pos}_{new} = \vec{Pointer} + (\vec{Pos}_{old} - \vec{Pointer}) \times \frac{Zoom_{new}}{Zoom_{old}}$$
- **核心数据隔离**：桌面上所有卡牌的 `CardData.Position` 保持原值不变，严禁在每帧物理或视口变换中写入逻辑存档！

### 2. UI 滚轮隔离与输入屏蔽
- 依据 R04 证据中的 `InputMgrComponent.PositionIsOverUI` 机制：
  - 当光标位于场所窗口、说明面板等挂载了 `ScrollRect` 的 UI 之上时：
  - EventSystem 捕获 `IScrollHandler`，滚轮增量仅用于滚动该面板内的卡槽或文字；
  - 桌面主相机的 `OnScrollPerformed` **完全被切断**，绝不触发桌面缩放。

## 三、视口边界保护（`lookBounds`）

根据逆向提取的 `CameraControl.lookBounds` 与 `RecalculateBoundingRect`：
1. **防脱轨软硬边界**：
   - 相机视口中心允许平移的最大范围限制在逻辑桌面外延 $20\%$ 缓冲区内；
   - 严禁相机将整张牌桌移出视口之外，保证桌面上永远至少有 $50\%$ 的区域在屏幕可视范围内。
2. **重置视口（Reset View）**：
   - 双击鼠标中键或按快捷键 `Space`（无选卡时），平滑插值复位相机至桌面正中心 `(800, 450)`。
