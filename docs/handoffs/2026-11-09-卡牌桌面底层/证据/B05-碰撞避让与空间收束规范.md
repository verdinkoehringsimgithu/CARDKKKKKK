# B05 - 碰撞避让、物理推开与桌面边缘收束规范

> **规范等级**：
> - **E1 / E2（物理避让动力学与空间松弛算法规范）**：对齐 R02 逆向发现的 `PushAwayFromOthers`、`Bounce` 与 `ClampPosBounds` 物理参数与动力学流程。
> - **核心准则**：严禁在密集区域或桌角产生无限高频抖动；处于任务锁定中的卡牌具有无限质量（不可被推开）；任何推挤计算必须在有限步内收敛，桌面边缘严格刚性收束。

---

## 一、物理推开与动力学松弛算法（Iterative Relaxation）

当卡牌被放置在桌面空白区域，但其碰撞体与邻近已有卡牌或牌堆发生重叠时，系统启动**有限步迭代松弛算法**：

```mermaid
flowchart TD
    DropCard[新卡牌落位: 目标中心 Pos] --> OverlapCheck{检测与周围卡牌的 AABB 重叠?}

    OverlapCheck -- 无重叠 (间距 >= Gap) --> Settle[落位稳定: 提交最终世界坐标]

    OverlapCheck -- 存在重叠 (Overlap > 0) --> LoopRelax[进入松弛循环: iteration = 1 到 8]

    LoopRelax --> CalcRepulsion[计算周围卡牌对当前卡牌的排斥向量 sumRepulsion]
    CalcRepulsion --> CheckLocked{周围卡牌是否为任务锁牌/常驻设施?}
    CheckLocked -- 是 (无限质量) --> OnlyMoveCurrent[当前卡牌独自承受全额位移排斥]
    CheckLocked -- 否 (普通自由卡牌) --> ShareMove[双方各承担 50% 排斥位移]

    ShareMove --> ApplyClamp[执行 ClampPosBounds: 强行将所有卡牌截断在桌界内]
    OnlyMoveCurrent --> ApplyClamp

    ApplyClamp --> CheckConverge{最大重叠量 < 容差阈值 (2px) ?}
    CheckConverge -- 已收敛 --> Settle
    CheckConverge -- 未收敛 且 iteration < 8 --> LoopRelax
    CheckConverge -- 超出 8 轮仍未收敛 (极端密集/死角) --> SpiralFallback[触发螺旋空位搜索算法 Spiral Candidate Search]
    SpiralFallback --> Settle
```

## 二、关键物理参数与常量表（严格参照 R02 逆向基准）

| 参数名称 | 建议取值 | 物理意义与约束 |
|---|:---:|---|
| `CardColliderWidth` | 100.0f | 卡牌碰撞体标准宽度 |
| `CardColliderHeight` | 140.0f | 卡牌碰撞体标准高度 |
| `SafetyGap` | 12.0f | 卡牌间的最小安全间距，小于此值产生排斥力 |
| `MaxRelaxationSteps` | 8 | 单次推挤最大迭代轮数，杜绝帧率骤降与死循环 |
| `ConvergenceEpsilon` | 2.0f | 重叠量小于 2 像素时视为平衡收敛 |
| `DeskMargin` | 16.0f | 桌面外圈安全内缩边距，卡牌不得越过此红线 |

## 三、静态不可动实体（Infinite Mass Obstacles）

1. **设施与建筑实体**：
   - 营地、工作台、采石场等常驻设施在桌面上具有固定锚点，其“质量”视为无穷大；
   - 任何飘落或推挤过来的材料牌只能绕行避让设施，设施绝对不被材料推开。
2. **任务加锁中的卡牌**：
   - 正在进行生产或研究的卡牌处于锁定状态，同样具有静态不可动属性。

## 四、桌角密集极端边界的螺旋兜底（Spiral Candidate Search）

在角落或三面受夹的极端密集情况下，排斥算法可能会因桌界反弹而陷入局部死锁震荡。

为保证绝对健壮性，系统配备**网格螺旋搜索兜底机制**：
- 一旦松弛计算达到第 8 轮仍未完全消除重叠：
- 系统立即从目标中心点出发，沿顺时针阿基米德螺旋线（以步长 $24\text{px}$）采样最近的合法无重叠空位：
  $$r = a + b\theta, \quad x = x_0 + r\cos\theta, \quad y = y_0 + r\sin\theta$$
- 强制将卡牌平滑弹落到采样出的最近有效空位上，确保 $100\%$ 在桌界内可见且可被玩家再次拾取。
