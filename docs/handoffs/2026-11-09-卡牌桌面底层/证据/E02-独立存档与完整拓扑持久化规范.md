## 三、三级安全写入与恢复恢复机制

1. **写临时文件落盘**：写入 `voyage-manual-v1.json.tmp` 并调用操作系统级 `Flush(true)`；
2. **滚动保留历史备份**：若原 `voyage-manual-v1.json` 存在且 SHA256 合法，将其安全原子移动至 `voyage-manual-v1.json.bak`；
3. **完成原子替换**：将 `.tmp` 重命名覆盖为主存档；
4. **坏档自愈策略**：读取主存档时若发生哈希校验失败或 JSON 解析崩溃，核心自动尝试静默回退加载 `.bak` 备份，并在界面提示：“检测到主存档异常，已为您恢复最近一次有效备份”。
