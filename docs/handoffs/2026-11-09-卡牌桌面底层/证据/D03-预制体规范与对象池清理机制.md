# D03 - 真实 Prefab 结构、对象池复用与资源清理规范

> **规范等级**：
> - **E2 / D（工程化 Prefab 架构与对象池内存生命周期规范）**：落实《协作约定》对“编辑状态下要有可见内容”、“优先修改真实 Prefab 序列化层级而不靠启动器代码硬拼界面”的硬性要求。
> - **核心准则**：场景在未运行（Edit Mode）时即可直观看到桌面、卡牌与场所示例；对象池复用时必须进行彻底的“零残留状态清洗”；场景注销时必须彻底退订事件与清理材质。

## 一、真实序列化 Prefab 层级与编辑态可见性标准

```text
TableSceneRoot (场景根节点)
├── BackgroundCamera (背景独立相机，固定 ClearFlags=SolidColor)
├── TableCanvas (1600x900 逻辑桌面 CanvasScaler)
│   ├── TableSurface (暗色木纹桌面 Image)
│   ├── TableCardLayer (L1: 桌面卡牌与场所常驻实体)
│   │   ├── SampleDeskFacility (编辑态可见的场所实体示例，带 timer_progress)
│   │   └── SampleDeskCards (编辑态可见的卡牌示例，用于美术对齐间距)
│   ├── ActiveDragLayer (L3: 抓取飞行动画置顶层)
│   ├── FacilityWindowLayer (L4: 场所局部弹窗容器)
│   │   └── SampleFacilityForm (编辑态可见的工坊窗口 Prefab，带主槽与副槽)
│   ├── TooltipLayer (L5: 详情提示与气泡)
│   └── SystemModalLayer (L6: 系统菜单与设置)
```

- **禁止黑盒拼接**：启动脚本 `Bootstrap` 仅负责绑定核心引擎数据，绝不通过 `new GameObject().AddComponent` 动态捏造 UI 层级。

## 二、对象池（Object Pool）绝对零残留清洗协议（Sanitization Protocol）

当 `TableCardView` 被回收入池（`pool.Enqueue(card)`）或从池中取出（`pool.Dequeue()`）时，必须依次执行以下 6 步强力清洗：

```csharp
public void SanitizeForReuse()
{
    // 1. 强力杀死可能附着在该卡牌上的全部活动 Tween 与协程
    StopAllCoroutines();
    transform.DOKill(false);

    // 2. 变换重置
    rectTransform.localScale = Vector3.one;
    rectTransform.localRotation = Quaternion.identity;

    // 3. 视觉状态复位
    selectionBorder.enabled = false;
    highlightImage.color = Color.white;
    progressBar.fillAmount = 0f;
    gearIcon.gameObject.SetActive(false);

    // 4. 事件与监听全退订
    UnbindAllEvents();

    // 5. 材质复位 (避免继承上一张牌的置灰或外发光材质)
    cardImage.material = defaultMaterial;

    // 6. 重置所有内部临时标志
    isDragging = false;
    currentSlotId = null;
}
```

- **效果保证**：取出的卡牌永远处于崭新纯洁状态，绝不携带上一张卡牌遗留的红色排斥框、倒计时进度或拖拽残余。

## 三、场景切换与销毁时的内存生命周期

在所有 View 脚本的 `OnDestroy` 与 `Unbind` 方法中：
1. **统一退订引擎事件**：
   - 彻底注销 `Engine.Changed -= Render`、`controller.Sound -= PlaySound` 等委托，防止死引用的 Mono 实例在后台继续被调用并引发 `MissingReferenceException`；
2. **清理动态创建的资源**：
   - 销毁通过 `new Material(desaturateShader)` 或 `Font.CreateDynamicFontFromOSFont` 动态生成的临时资产，保持工程内存绝对干净卫生。
