# D01 - 表现层动画参数、缓动曲线与取消中断规则规范

> **规范等级**：
> - **E2 / D（表现层动力学参数与动画状态机规范）**：定义桌面卡牌从移动、回弹、吸附、飞出到销毁的 7 类动画时间与缓动参数，建立动画中途重开/读档时的绝对安全性中断准则。
> - **核心准则**：核心状态永远先于动画提交；严禁在动画完成回调（OnComplete）中执行业务扣料或发牌；动画中途重开或读档时，视觉必须能无条件瞬时对齐快照。

---

## 一、七类卡牌核心动效参数与缓动曲线标准表

| 动效类型 | 触发场景 | 持续时长 (Duration) | 缓动曲线 (Ease Curve) | 轨迹与参数特征 |
|---|---|:---:|---|---|
| **`MoveSmooth`** | 桌面卡牌常规位移 / 整理桌面 | 0.18s | `EaseOutQuad` | 线性平滑插值，无冲过头振荡 |
| **`DropBounce`** | 正常松手放置于桌面 | 0.12s | `EaseOutBack` (微弱) | 纵向微弹（缩放 $1.04 \to 1.0$），提供扎实质感 |
| **`RejectBounce`** | 非法目标 / 按 Esc 取消拖拽 | 0.18s | `EaseOutCubic` | 从悬空点平滑插值原路飞回原始记录坐标 |
| **`SnapInSlot`** | 吸附进入场所卡槽 | 0.12s | `EaseOutBack` | 卡牌快速吸合至卡槽中心并触发入槽轻微收缩 |
| **`ParabolicFlyOut`** | 产物从场所 cardGrid 弹飞至桌面 | 0.35s | 抛物线插值 (`Parabola`) | 弧高 $H = 60\text{px}$，水平位移与纵向抛物线同步 |
| **`MergeSlide`** | 落地后自动合入已有兼容牌堆 | 0.15s | `EaseInOutQuad` | 平滑滑入牌堆顶部，层级无缝衔接 |
| **`Disintegrate`** | 消耗品扣除 / 腐坏销毁 | 0.25s | `EaseInQuad` | 缩放 $1.0 \to 0.0$ 叠加 Alpha 淡出，随后入池回收 |

## 二、动画中断与瞬时快照对齐准则（Snapshot Alignment Rule）

在许多劣质实现中，程序员常常把“发放物资”或“扣除体力”写在 `DOTween.OnComplete(() => { GiveReward(); })` 中。一旦玩家在动画播到一半时快速按 Esc 打开菜单、读档或重开，就会导致回调漏发（吞材料）或读档后迟到执行（把上一局的产物发到了新一局里）。

本项目立下**铁律**：

```mermaid
flowchart TD
    TxCommit[核心原子提交: State Revision++] --> DispatchEvent[发布领域事件: CardDetachedFlyEvent]
    DispatchEvent --> StartAnim[表现层启动协程/Tween 播放飞行动效]

    subgraph InterruptEvent [突发中断: 读档 Load / 重开 Restart / 切场景]
        AbortSignal[收到中断信号]
    end

    StartAnim -. 飞行中途 .-> AbortSignal
    AbortSignal --> KillTween[立即强行杀死全部活动 Tween: Kill(false)]
    KillTween --> SnapToState[瞬时对齐核心快照: Transform.position = Snapshot.Position]
    SnapToState --> SafeFinish[安全达成一致状态: 零悬空对象, 零重复扣费, 零幽灵卡]
```

1. **状态驱动，动效脱耦**：
   - 动画仅仅是“已经发生了的事实”的延时播放；
   - 任何破坏性中断发生时，调用 `KillAllRunningAnimations()`，直接把视图 GameObject 的位置强制赋值为当前核心快照记录的坐标，立刻收束，不留任何延迟回调。
