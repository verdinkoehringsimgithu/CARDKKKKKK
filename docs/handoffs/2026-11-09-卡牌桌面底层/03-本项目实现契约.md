## 唯一状态

- `CardInstanceId` 稳定标识实体；DefinitionId只标识类型。两张手是两个实例。
- 每实例同时只能有一个逻辑归属：桌面、某堆、某槽、某任务、某容器之一。若“任务锁住槽中牌”需要双引用，必须区分所有权与锁，并校验互反引用。
- 堆ID、槽ID、场所ID、任务ID不混用；父子引用无环；销毁要同时清理索引、锁、选择、悬停和连接。
- 堆叠是组织关系；合并转化是配方；数量批次合并是库存操作。三个命令不能共用一个含混的 Merge。
- 不同磨损/到期时间/伤势关联的实例不能为堆数量而合并丢状态。
- 拖动视觉是预览，不边拖边修改已提交坐标；松手一次性提交，拒绝恢复。

## 建议命令边界

以下是职责名称，不要求照搬类名：

| 命令/查询 | 输入与职责 | 不应做什么 |
|---|---|---|
| BeginDrag / UpdateDrag / CancelDrag | 捕获实例集合与原位置、修饰键、预览坐标 | 不消耗物资，不提交每帧存档 |
| QueryDrop | 同时返回候选目标、动作类型、是否合法、原因与预览位置 | 不让UI另写一套配方匹配 |
| CommitDrop | 在最新状态再次校验候选，事务提交移动/叠牌/入槽等明确行为 | 不相信过时高亮，不忽略目标已消失 |
| AssignSlot / RemoveSlot | 实例和槽位绑定、限制与占用 | 不把引用列表当作可重复借用库存 |
| QueryRecipes / QueryCandidates | 已知配方、缺少标签/数量、可用实例与原因 | 不泄露未知配方，不推荐被锁牌 |
| StartTask / CancelTask / CompleteTask | 核验并预留、锁定、结算、释放；结算幂等 | 不从动画回调开始扣料或发牌 |
| AdvanceClock | 按确定事件顺序推进工作、寿命与恢复 | 不使用Tween时间作为核心计时 |
| Capture / Restore | 拷贝、验证并恢复整体状态 | 不部分恢复一半后写入自动档 |

成功结果建议携带递增状态版本和展示事件，如 Moved、StackChanged、SlotAssigned、TaskStarted、CardsProduced。事件指向已提交状态；是否新增此结构先审查现有接口。

## 目标判定

统一命中服务排除自身和拖动集合、不可交互对象、被遮挡对象、已锁对象；区分UI与桌面命中。排序规则配置和文档明确后固定，预览与提交共用。优先级仍待R02确认，不写死猜测的原作顺序。

每次拖动只更新候选变化和视觉位置；不每帧全量配方组合搜索、全桌重建UI或重新扫描所有牌。几何索引按实例边界维护；堆和窗口用整体边界。空间无解必须有限次返回结果，不能无限推挤。

## 归属与动画

新产物先提交实例、归属和目标落点；表现事件记录来源、去向、批次和动效类型。视觉飞行期间是否可抓取是显式输入策略，不能靠“还没Instantiate”决定存在与否。重开、读档、切场景应取消动效并直接对齐当前快照，不补发逻辑事件。

重叠与吸附预览可使用表现坐标，但最终占位与归属必须来自核心。碰撞弹开若会改变持久位置，需提交明确的布局结果；不能让物理帧悄悄改存档。

## 场所窗口

每个场所实例绑定自己的准备槽与任务。窗口开关只改变显示；是否退回准备牌由明确命令决定。执行中窗口关闭不默认取消任务。卡面、槽、任务进度需能追踪参与实体，不能把任务列表变成唯一操作空间。

窗口由实际Prefab配置，支持标题、输入槽、可用/缺失条件、产物预览、工作进度、恢复进度、开始/取消/关闭。按场所能力显示必要部分，不铺常驻操作指南。输入槽可滚动但不遮按钮。

## 时钟与输入

暂停原因至少区分用户暂停、模态阻塞、失焦和场景退出；解除一个原因不能覆盖其余原因。时间策略先沿用项目设计，不凭参考游戏的 Pause 字段推断最终体验。暂停不禁止整理和查看，只按具体状态限制占用牌。

键鼠输入集中路由，窗体获得焦点时阻止桌面快捷键；鼠标松手即使落在桌外或UI上也终结会话。读档/目标失效/失焦/退出需要统一CancelDrag与清理路径。

## 配置、保存与验收边界

名称、分类、序号、初始实例属性和插画读CardDefinition；行为规则从配置真正传至Core。动效时长、缓动、弹出间距、层级色和音效放表现主题；不要把参考包里的具体参数未经核实复制成默认值。

存档保存逻辑位置、身份、归属、堆、槽、任务、剩余时间、稳定随机状态和连接。不要保存悬停、鼠标指针、Tween回调或Unity对象引用。恢复先整体校验，再重建显示。

本轮与后续代理均不自行启动Unity、编译器或测试命令。可以新增可审查的验收场景/回归源码及静态检查；实际运行由用户执行。不得以静态解析成功写“玩法测试通过”。
