# Delivery Review

Review the actual deliverable and available verification once before handoff:

- Does it satisfy the requested outcome and constraints without unrequested features or unnecessary complexity?
- Does it address the responsible mechanism and preserve affected interfaces, state ownership, and downstream behavior?
- Do the checks cover the relevant integration path? Separate isolated test results from evidence about the full system.
- Can someone use the artifact without the conversation history? Remove session commentary while retaining necessary rationale and diagnostics.

Fix concrete gaps within scope. Report the outcome, relevant checks, and unresolved limitations; no mandatory report template or additional skill invocation is required.
