# Evidence Loop

- Choose checks that demonstrate the requested behavior in the relevant environment.
- Inspect the result after changing it. If a check fails, investigate before retrying; repeat checks only when changes or unresolved failures justify it.
- Distinguish an implemented change, an executed test, and behavior verified under specific conditions. Test success supports only the scenarios it covers.
- Report the result, meaningful evidence, and material limits concisely. Never claim an unrun check passed or an isolated check proves end-to-end behavior.
