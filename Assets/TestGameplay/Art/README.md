# 测试工坊美术

本目录只给独立测试玩法使用，不改原牌桌主题。

## 画风

统一为土色手绘：暖米色纸张、赭石陶器、低饱和植物和铜矿、深棕轮廓、左上方柔光、哑光材质。没有发光霓虹、写实照片、金属UI装饰或混用像素图。

16个对象在同一张4×4图集中生成，卡框再引用该图集作画风参考。生成工具为SpriteCook，模型GPT Image 2.5 Flare，1K；未使用image技能补图。背景去除也通过SpriteCook完成，最终透明边缘和卡框中心已查看。

## 实际使用

- 工坊物件图集_透明.png：运行及Prefab引用；Unity Multiple Sprite，16个256×256切片，双线性、Clamp、无mipmap、无压缩。
- 工坊卡框_透明.png：单个Sprite，原图中的非透明区域经Sprite矩形裁出；四边64像素九宫格，PPU400，保护边角且让大图边框按UI尺度显示。
- 不带“透明”后缀的两张PNG是生成原图留档，不绑定游戏。
- 配置中每种物品与工位均有独立Sprite引用，可替换其中一张；补图时必须沿用本画风，并引用本批图作参照。

图集从左至右、从上至下：

| 行 | 对象 |
|---|---|
| 1 | 木料、黏土、纤维、铜矿 |
| 2 | 木炭、灰、焦油、陶坯 |
| 3 | 坩埚、铜锭、铜斧、工作台 |
| 4 | 土窑、林地、河滩、矿点 |

灰色陶坯与橙色坩埚的区别保留在图上。地点也使用透明小景，没有单独的大背景。全部名称、数量、进度和按钮文字由Unity绘制，没有烘焙进图片。

spritecook-assets.json保存资产ID、文件摘要和名称，不保存签名下载地址或凭据。生成提示词在生成提示词.md；新旧资产均保留来源，便于后续一致地补图。

## 中文字体

NotoSansCJKsc-Regular.otf来自[Noto CJK官方项目](https://github.com/notofonts/noto-cjk)，许可保存在字体许可.txt。字体仅被新测试模块引用，让编辑态和运行态都能显示中文，不依赖操作系统是否装有微软雅黑。
