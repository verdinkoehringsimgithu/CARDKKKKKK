# 孤岛规则底层

本模块位于 `Assets/TestGameplay/IslandFoundation`。Core 不引用 Unity 或旧牌桌，Unity 引用 Core，Editor 引用前两者。`IslandSession` 是场景里的调用入口。输入组件提交实例 ID 与槽位绑定，显示组件订阅 `Changed`，文件接口保存或恢复 JSON。三者可分别接入。

## 配置与使用

1. 选中 `Configuration/底层示例配置.asset`，在 Inspector 点击“校验定义与开局”。
2. 菜单“孤岛底层/在当前场景创建会话（使用选中配置）”生成一个已绑定配置的对象，可撤销。建议在独立调试场景操作。
3. 用户自行进入 Play，选中会话。在调试 Inspector 的区域 ID 填 `garden-1`，配方选“提取凝胶”，material 填 `material-1`，knife 填 `knife-1`，点击“提交配方”。
4. 提交成功后，芦荟肉从3减到2，刀的 durability 从3减到2，生成待完成任务。推进5分钟后，花圃内增加凝胶和残渣各1。第60分钟示例篝火到期，生成灰烬。示例中的数量、时间与容量仅作底层操作样例。
5. “导出快照到下方”获得包含实例、数值、归属、时钟和任务的JSON。“从上方快照恢复”重新校验整个状态，任务继续按保存的完成时刻结算。

以上是预期操作结果。本轮按项目要求未运行 Unity、编译器或测试，尚待实际验证。

## 数据边界

- 五类卡牌共用实例表示。卡牌定义负责名称、分类、标签、初始数值、堆叠上限、容量、寿命与耗尽产物。运行实例只引用定义ID，保存数量、位置、归属、当前数值和到期时间。
- 区域的内容通过实例 `RegionId` 关联，空值表示桌面。区域不互相嵌套。区域内坐标为相对坐标，移动区域只改变区域坐标，成员可由视图组合计算世界位置。到期区域释放成员到桌面，坐标转换回桌面坐标。
- `Capacity` 按实例计数，一堆材料占一格，当前任务的未来产物也占预留格。各产物按定义的堆叠上限新建批次，不自动与旧批合并，保留各自寿命。
- 配方槽位可要求指定定义，也可要求全部标签和最低数值。每槽显式绑定一张实例，多槽不可复用同一实例。`Consume` 扣对象数量，支持材料加工、工具拆解或生物收获，区域不直接消耗。其他参与物工作期间保留并锁定归属。`ValueChanges` 支持负数损耗与正数修补，数值低于0时拒绝整个操作；当前只支持非负整数数值，标签不承担数值运算。
- 硬度、耐久、燃料等均可由数据里的数值键表达。Core 没有贝壳、芦荟、篝火、铜斧等名称判断。数值增长上限及维修递减等进一步规则需要后续明确后接入。
- 空间移动命令只管理归属和坐标。碰撞、拖动、框选和牌堆排布继续由桌面表现模块负责。新模块目前通过调试 Inspector 操作。

## 状态一致性

- `Move`、`StartRecipe`、`AdvanceTo`、`Restore` 都先复制状态，再执行和校验，一次提交。被拒绝的命令不扣料、不改变时间或版本号。
- 配方在开始时扣材料与数值，剩余参与对象锁定至完成。预留所有任务产物的全局实例数和区域容量，防止并发任务超卖空间。只有同一区域里的对象能一起参与，区域实例本身也可作为该区域的条件。
- 参与对象到期时，关联任务取消，开工已经消耗的材料与数值维持已支付状态。耗尽产物按原堆数量计算。区域到期时，其他任务的产出归属转回桌面。
- 相同分钟先结算到期，再完成配方。到期和任务完成各按稳定实例ID排序。新产物在实际生成时开始寿命。`AdvanceTo` 跳到下一个事件时刻，不逐分钟扫描。单次事件批次数由配置限制，过大跨度整体拒绝，可缩短推进时间后重试。
- 若耗尽产物使容量不足，整个时间推进回滚并给出错误，玩家需腾出空间后重试。配方输出提前预留，耗尽产物目前使用这项阻塞策略。后续应结合桌面规则决定废物溢出策略。
- 快照结构版本固定为1，内容版本由配置填写。定义或配方规则变化时需主动更新内容版本，旧版本恢复会被拒绝。本模块提供快照序列化入口，磁盘原子保存、备份和迁移尚待文件接口接入。
- 所有命令由所属线程串行调用，观察者获得独立快照。观察者异常记录到 Unity Console，不能改变已提交结果，通知期间拒绝重入修改。

## 本轮边界

已提供数据驱动的卡牌、区域归属、标签与数值匹配、实例损耗和修补、延迟配方、主副产物、寿命耗尽和快照恢复。自主生态周期、天气、遗传、育种、角色需求、造船流程与玩家牌桌界面留待按具体设计接入。示例只用于检查底层入口。
