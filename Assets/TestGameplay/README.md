# 独立测试玩法

当前入口为“测试玩法”，运行Assets/TestGameplay/Spellcraft/Scenes/Spellcraft.unity。原自由牌桌保持原样；进入时暂停、返回时恢复原牌和位置。

用户于2026-11-05选择“把法术拆开，重新拼触发条件、效果和改装”。当前实现包括三个装置槽、回合战斗、完整连锁预演、四场遭遇、战后零件选择、中文规则配置与独立存档。玩法和修改位置见[法术拆装说明](Spellcraft/README.md)。

运行原场景后点左上角“测试玩法”，在装配台点击装置改接零件，点“进入试炼”。战斗先点敌人，再点手牌或手动装置。规则来自Spellcraft/Configuration/法术工坊配置.asset。

界面已改为1600×900逻辑桌面等比适配，拆装页与主桌面分开显示。Esc开关菜单，保存、读取、重新开始和返回牌桌集中在菜单中；关闭拆装页也可按Esc。调整后停止当前Play并重新进入测试玩法，加载新Prefab。

旧八配方造斧原型已停用并清理代码、配置、场景和Prefab；如需查历史，查看303ce22。原Art目录保留中文字体、许可与旧图片留档，新实际资源位于Spellcraft/Art。旧存档不迁入本模式。
